# Database-Course

Database Project - Bouwcontrole

In dit bestand zal ik je het proces tonen van mijn database project waarin ik eerst zal beginnen met het bouwen van een ERD schema voor de Database die ik later zal opzetten voor mijn C# project voor het vak Programming Advanced. Dit zal als ruggengraat dienen om later het ERD gemakkelijk om te kunnen zetten van een tekening (blauwdruk) naar de technische realisatie, zodat een SQL, PostgrSQL of MySQL server later dit kan gebruiken. Ik zal later de database dan ook vullen met gegevens voor een PostgrSQL server en SQL server.

Je zal hier ook afbeeldingen te zien krijgen van het heel proces. Je krijgt het ERD te zien en later ook de boomstructuur van het SQL schema. In het laatste stadium zal je de NoSQL realisatie ook te zien krijgen.
