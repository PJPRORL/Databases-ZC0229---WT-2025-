## Database Project - Bouwcontrole

Vanaf dit punt zal ik je het proces tonen van mijn database project waarin ik eerst zal beginnen met het bouwen van een ERD schema voor de Database die ik later zal opzetten voor mijn C# project voor het vak Programming Advanced. Dit zal als ruggengraat dienen om later het ERD gemakkelijk om te kunnen zetten van een tekening (blauwdruk) naar de technische realisatie, zodat een SQL, PostgreSQL of MySQL server later dit kan gebruiken. Ik zal later de database dan ook vullen met gegevens voor een PostgreSQL server en SQL Server.

Je zal hier ook afbeeldingen te zien krijgen van het hele proces. Je krijgt het ERD te zien en later ook de boomstructuur van het SQL schema. In het laatste stadium zal je de NoSQL realisatie ook te zien krijgen.
